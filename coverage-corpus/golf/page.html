256-Line Compiler Golf

How much of the Scala 3 compiler can one source file make run? Every track: a single .scala file of at most 256 lines, ordinary formatting, no semicolons, compiled with plain scalac (no options, no //> using directives). Score: JaCoCo line coverage of the whole compiler for that one compilation, including the code every compilation runs.
